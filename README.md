# Australian ecommerce workbench

面向中澳跨境店主的经营工作台。当前分支为 **v2.0.0-alpha.1：店主工作流架构版**。

登录已改为自托管邮箱 + 密码体系，不再依赖 Kimi OAuth；仓库根目录同时提供
Docker Compose + Caddy + MySQL 的服务器部署配置。

## 版本隔离

| 版本     | 管理方式                                      | 用途                               |
| -------- | --------------------------------------------- | ---------------------------------- |
| 原版     | `main`，本次改造的原版基线为 `3bcde3f`        | 保留原有页面组织与行为，不直接覆盖 |
| v2 Alpha | 独立功能分支与独立 PR，包版本 `2.0.0-alpha.1` | 评审新的业务模块与店主操作链路     |

本次发布不合并 `main`，也不复制一套 `v1/`、`v2/` 业务代码在同一运行时里维护。两版使用相同数据库结构，**共享实际数据库意味着共享业务数据，不意味着环境隔离**；评审新版请使用独立测试数据库和独立平台应用配置。

## 新版操作主线

今日经营 → 订单队列 → 商品匹配 / 缺货补货 → 采购收货 → 重新检查库存 → 打包交运 → 平台状态核对。售后拥有独立入口，并保留订单上下文。

- 首页先展示生意概况和今天要做的事；没有依据的利润不显示为零。
- 订单以待发货、缺货 / 待匹配、已发货、售后分队列，手工录入不再占据主页面。
- 从订单直接带入发货，默认填写剩余可发商品，并扣除已有草稿包裹数量。
- 库存先回答还能卖多少、订单缺多少、采购在途多少，再展开账本与批次。
- 退款、退货验收、实际交运与平台更新分别记录，不自动推定外部执行成功。

## 登录与部署

- 首次启动在 `/login` 创建管理员，或通过 `ADMIN_EMAIL` / `ADMIN_PASSWORD` 自动创建
- 密码使用 scrypt 加盐散列；会话是 HttpOnly、SameSite=Lax Cookie，重置密码会立即使旧会话失效
- 管理员可在「系统设置 → 成员与角色」添加成员、启用密码登录和重置密码
- 腾讯云服务器部署步骤见 [docs/deployment-tencent-cloud.md](docs/deployment-tencent-cloud.md)
