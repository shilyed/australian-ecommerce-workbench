# 澳洲电商趋势机器人需求报告

版本：1.0；日期：2026-10-28；状态：实施基线，**不是实时采集结果或上线证明**。

本文件先于实现代码独立提交并发布到本仓库的功能分支。实现、运行说明和验收记录随后提交，
不以需求报告替代实际交付。部署目标为用户的腾讯云 Linux 个人服务器；目前尚无主机访问权限、
采集服务凭证、邮件配置或 DeepSeek 密钥，因此不能声称已部署或已实时联通。

## 1. 业务目标

为跨境电商经营者持续观察一个可配置的澳洲消费赛道，先以“咖啡杯”为例，回答：

- 观察样本中，哪些商品或内容受到关注？哪些材质、容量、杯盖、保温结构、颜色、风格和场景反复出现？
- 哪些有可核验的澳洲买家成交证据，哪些仅有全球社媒互动或澳洲搜索兴趣？
- 与上期相比，哪些变化有足够的同口径证据，哪些仍是待验证的选品假设？

交付中文 HTML 周报和 CSV 明细，可通过邮件或已配置的 HTTPS webhook 通知。
报告辅助人工选品，不自动采购、发布商品、修改价格、预测确定利润或操作原网站业务。

## 2. 范围和非目标

### 首期必须实现

1. 独立配置赛道名称、关键词和特征词典；默认提供咖啡杯实例。
2. eBay AU 在售商品发现和已有商品复查；TikTok 关键词发现和已知视频复查；
   Google Trends 澳洲搜索兴趣自动后端，以及明确标注的授权文件导入。
3. SQLite 持久化快照、来源状态、授权导入记录、任务和通知幂等记录。
4. 按实际时间计算观察区间增量、完整周窗口、来源内部排名、特征分布和数据质量。
5. 本地周报、CSV、可选 DeepSeek 摘要、可选投递，以及可重启的日采周报调度。
6. 无密钥、无网络、无付费调用的独立演示和自动验收命令。
7. 隔离的容器、配置、存储、备份、升级和腾讯云部署说明。

### 后续范围

Instagram / Facebook 的专业账号、公共主页数据接入，必须先具备适用账号、App Review、
business verification 和实际获批权限。首期保留显式“未接入／权限待确认”状态，
**不以空数组、占位成功或假数据冒充已实现适配器**。

### 非目标

不覆盖澳洲全量市场，不保证发现真正的全市场销量冠军；不绕过登录、验证码、付费墙、
私有群组、账号权限或服务条款；不以 TikTok Research API 作为商用默认方案；
不依赖已废弃的 eBay `findCompletedItems`；不新增网站仪表盘、多租户、消息队列或复杂爬虫集群。

## 4. 赛道、地区和证据口径

赛道以稳定标识、中文名称、英文搜索词和特征词典配置。关键词变更产生新的配置指纹，
报告记录该指纹；不同赛道或配置不能悄悄混成同一可比样本。

每条明细保留来源、外部 ID、公开链接、检索词、采集时间、指标缺失原因和证据类型。
按可获得字段分别记录：

- 站点／市场：如 `EBAY_AU`；只表示所检索的市场。
- 商品／卖家所在地：仅按接口真实字段命名；商品所在地不能冒充卖家注册地。
- 创作地区／澳洲标签／关键词相关性：弱或中等内容相关证据。
- 买家国家：只有授权成交记录的明确字段才可支持 AU 买家成交。
- 观众国家：未知时必须写未知；澳洲创作者的全球指标仍是全球指标。

去重首先依赖平台和外部 ID；同一视频被多个关键词发现只计一次，保留其检索上下文。
不同视频、不同商品或跨平台“相似款”不做无依据的实体合并。

## 5. 时间、增量和排名

数据库保存带 UTC 时区的时间；调度和业务周使用 `Australia/Sydney`，自动处理夏令时。
周窗口为当地周一零时起至下周一零时止，采用左闭右开 `[start, end)`。
完整当地七天不保证等于 168 个 UTC 小时；上一周采用相邻当地日期重新构造。

### 社媒

累计播放、点赞等保留原始快照，未知值不填零。
只有同一对象的真实前后快照才能计算增量；任何缺失或计数回退／重置使对应增量不可用。
完整周增量只有在窗口两端有真实边界快照且中间无异常时才标为完整；
通常日采只能得到部分观察区间增量，必须展示实际起止、覆盖程度，
**不能把部分观察区间增量命名为完整本周流量**。
无基线的新对象可展示累计指标和发现时间，不伪造周增量或环比。

TikTok 在本平台内部展示“样本观察区间增量排行”和独立的“累计播放样本”。
所有社媒指标均标明非 AU 观众证明、非成交。不同观察区间的排行存在覆盖偏差，报告必须提示。

### 成交

只有 `sold_at` 在本周内、买家国家明确为 `AU` 的逐条授权成交才计入 AU 成交样本排行。
非 AU、未知买家国家、其他时间的记录须排除并报告数量。
明确区间的第三方估算另表展示，仅在区间完整位于所述窗口时使用，不与成交相加。
滚动三十天销量独立保留原口径，**不差分、不除以天数换算七天销量**。
没有合格成交证据时明确“本周 AU 买家销量未知”。

### 搜索兴趣

同时比较当前周和上一周时，只能使用同一份请求／同一次导入内的可比序列；
每日重新归一化的响应单独保存，不能拼接成销量或跨请求的绝对变化。
日粒度、非部分数据点且完整覆盖两个窗口才计算周均兴趣环比；
缺失／部分／周粒度、旧数据和上一期为零须显式解释。
不同查询组的 0–100 不合成跨平台总分。

### 特征

确定性词典提取咖啡杯材质、容量、杯盖、双层／保温、颜色、风格、场景等可观察特征。
报告区分“标题／文案命中”和产品实际认证，不把文案当作实测性能。
各来源独立统计特征样本数；成交数量、社媒播放和搜索兴趣不直接相加，不生成虚假的统一热销榜。

## 6. 报告结构

下列仅为**结构示意，非实测数字或经营建议**：

1. 赛道、配置指纹、报告版本、当地周窗口／UTC 边界、生成时间、LIVE／DEMO 标识。
2. 来源状态：已配置、成功／空样本、部分失败、未配置、待权限、预算阻塞；样本覆盖和最后采集时间。
3. eBay AU 在售样本：相关性顺序、价格、商品所在地、来源链接；注明不是销量排行。
4. AU 买家授权成交样本榜，第三方估算独立表；没有数据时写未知及原因。
5. TikTok 观察增量榜与累计值表，实际观察时间、缺失／重置、地区证据和置信度。
6. 澳洲搜索兴趣：查询词、同份序列的覆盖日期、周均兴趣、可用时的环比及限制。
7. 来源内的特征分布、可检索明细和选品假设；可选的 AI 摘要单独标明模型、状态和限制。
8. 数据质量和行动项：补充基线、补充授权成交、核实产品特征／成本，而非确定利润。
9. CSV 明细：与 HTML 同口径，保留来源和时间，不包含凭证、个人买家信息或原网站数据。

报告和明细须做 HTML 转义、链接校验、CSV 公式注入防护及密钥脱敏。
未配置／失败的 AI、来源和投递必须在机器可读结果与人类报告中可见。

## 7. 日采、周报和可靠性

默认当地每日 06:00 发现并复查受数量限制的现有样本；当地周一 08:00 输出上一完整周。
调度时间可配置，进程可用 Docker 自动重启。补跑只采集当前真实快照，
不会把今天的指标回填为错过日期的历史数据；周报可从已有证据有限补跑。

任务键、外部 ID、快照时间和报告版本持久化；单机任务互斥。
中断后的已知 Apify run 应继续查询，不能重新启动收费任务；
启动响应丢失等不确定状态停止自动重试并要求人工核对。
幂等报告不会因重复执行重写已投递内容；修订报告用明确的新版本。

通知采用持久化 outbox。SMTP 并不保证严格 exactly-once；
发送成功但本地确认前崩溃可能形成不确定状态，默认不自动重发以防重复邮件。
提供查看／人工确认或允许重试的操作。失败投递或未配置投递不得标成“已送达”。
可配置渠道同时承担周报中的降级提示和采集失败告警；全无通知配置时用非零退出码、
持久化状态和容器日志明确告警，不承诺不存在的外部通知。

所有 HTTP 设置连接／读取超时、响应大小上限、速率间隔和有界安全重试。
收费或可能产生副作用的请求不盲目自动重试。校验响应结构和数值范围；
无效批次不得悄悄丢弃坏行后仍宣称完整成功。

## 8. DeepSeek 可选接入

使用 OpenAI 兼容的 `POST https://api.deepseek.com/chat/completions`。
模型环境可配置，示例使用当前文档列出的 `deepseek-flash`，不依赖过期模型别名。
用户在服务器独立环境文件中配置 key，**不在聊天、git、报告或日志中提交密钥**。

只有显式启用并同意发送公共证据摘要才调用；发送经筛选和限长的公开标题、特征、
来源引用与确定性汇总，不读取原网站数据库，不发送买家身份、完整私有成交导出或服务器环境。
AI 只生成带有效证据引用的定性假设，数值和排行永远来自确定性代码。
输出需结构校验，禁止生成销售／利润数字或改写证据；不把模型文字当成事实验证。
未启用显示“未启用”，网络、额度、模型或格式失败显示“失败”及脱敏原因；
确定性报告仍生成，但明确降级，不冒充已完成 AI 分析。

## 9. 成本、保留和授权

默认小样本：每个平台／关键词数量、复查数量、每日 HTTP 请求数、每日收费调用数、
Apify 单次费用和月度费用上限、AI 输入长度／输出 tokens 都必须有界。
收费调用前持久化预留预算；不确定失败也不能自动释放额度造成无限重试。
具体服务价格／免费额度取决于用户账户和供应商当前报价，不保证免费或固定月费。
预算仅是本机器人调用上限，不控制用户账号中其他程序消费，用户应另设供应商额度告警。

不自动购买账号／额度、不在无明确授权时启用收费来源。
公开内容也可能受平台使用条款和个人信息规定约束；默认只存报告所需的最小文本和指标，
不下载视频、头像、评论明细、买家个人资料或访问私有内容。
提供备份和显式按天数清理数据；清理不触碰其他项目。

## 10. 与网站严格隔离

机器人所有代码、依赖、环境示例、Dockerfile、独立 Compose 和文档位于
`bots/au-trend-bot/`。不修改 `app/`、网站数据库 schema、网站包依赖、根 Compose、
根 `.env` 或网站平台凭证，不改变权限、交易状态或任何 marketplace 写入逻辑。
根 README 仅可增加文档入口。

独立 Compose project 名、SQLite 持久卷、导入目录和报告目录；默认无监听端口、
无公开 HTTP 服务，不占用网站 80／443，不连接网站 MySQL，不挂载 Docker socket。
容器非 root、只读代码文件系统、最小写目录和资源限制。
密钥保存在独立 `.env` 或服务器私密环境文件，权限最小化，构建上下文排除密钥和运行数据。

## 11. 部署和运维交付

提供腾讯云 Linux 上的 Docker Engine／Compose 前提、独立目录、环境配置、离线演示、
配置检查、首次采集、生成／投递、启动调度、状态和日志、备份恢复、升级回滚和停止步骤。
时区数据随运行环境提供，数据库 UTC；原网站不需停机或改反向代理。
备份使用 SQLite 一致性备份而不是直接复制正在写入的数据库文件。

当前 Windows 开发环境若无 Docker，不得把静态检查当作成功构建／容器验收。
真实部署须获得用户许可的主机访问方式后在目标机验收：
容器存活、独立持久化、时区／补跑、来源实际权限、报告投递和重启幂等。

## 13. 用户后续最小配置项

1. 腾讯云服务器 Linux 发行版／架构、SSH 访问方式或用户自行执行命令的方式、可用磁盘与内存；
   不要求在聊天发送密码或私钥。
2. 首期赛道／关键词确认（未另行指定则使用咖啡杯），报告接收邮箱或 HTTPS 通知地址。
3. 用户选择启用的来源：独立 eBay 应用／权限、Apify token／额度、可选 SerpApi key；
   没有这些时先用离线验收与明确标注的授权导入，不伪造实时能力。
4. 如需 AI，用户在服务器配置 DeepSeek key 和模型；如需 AU 销量证据，提供有权使用、
   带买家国家和时间字段的成交导出，不提供个人身份明细。
5. Instagram／Facebook 的实际业务账号／审批范围另行确认，不阻塞首期隔离交付。
